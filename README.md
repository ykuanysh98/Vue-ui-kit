# ku-ui-kit

Vue 3 үшін жеңіл, дизайн-токендерге негізделген UI компоненттер жиынтығы. Soft/rounded стиль, light/dark тема қолдауы бар.

## 🛠️ Технологиялық стек және қолданылған терминдер (Tech Lead-ке шолу)

Бұл кітапхана сіздің ортақ компоненттерді басқару, дизайн жүйелерімен және модульдік жүйелермен жұмыс дағдыларыңызды көрсетеді:

- **Модульдік жүйе (npm packaging):** Жоба NPM арқылы компоненттер кітапханасы ретінде әзірленіп, UMD және ES модульдік форматтарға жинақталып шығарылды (`ku-ui-kit`).
- **Документация (Storybook):** Storybook 8 (`@storybook/vue3-vite`), CSF форматы, Args/ArgTypes және оқшауланған компоненттер құжаттамасы әзірленді.
- **Дизайн жүйесі (Design System):** Ортақ дизайн элементтері мен стиль каскадтарына негізделген Design Tokens (CSS custom properties, tokens.css, light/dark mode) қолданылған.
- **Тестілеу (Testing):** Component және өзара байланыс тестілері `vitest` және `playwright` (браузерлік сынақтар) көмегімен жазылған.
- **Сборщик (Build Tools):** Vite
- **Фреймворк архитектурасы (Vue Architecture):** Слоттармен басқарылатын (Slot-driven) және Renderless компонент үлгілері.
- **Бағдарламалау тілі:** TypeScript

---

## Ерекшеліктері

- 🎨 **CSS Custom Properties (дизайн токендер)** арқылы толық теманы баптауға болады
- 🌗 **Light / Dark режим** — `.dark` класы арқылы автоматты
- 🪶 Жеңіл — Vue-дан басқа сыртқы тәуелділік жоқ
- 🧩 **Tree-shakeable** — тек қажетті компоненттерді импорттауға болады
- 🔌 CSS файлы міндетті түрде импорттаудың қажеті жоқ — компоненттер fallback мәндерімен де жұмыс істейді
